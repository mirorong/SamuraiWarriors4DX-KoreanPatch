# 전국무쌍 4 DX 비공식 한글패치

스팀판 **전국무쌍 4 DX (SAMURAI WARRIORS 4 DX)** 를 한국어로 즐길 수 있게 해주는 비공식 한글패치입니다.

> 📖 **설치 방법, 스크린샷, 업데이트 소식은 블로그에서 확인하세요**
> 👉 https://m-gororong.tistory.com

## 다운로드

[**최신 버전 받기**](https://github.com/mirorong/SamuraiWarriors4DX-KoreanPatch/releases/latest)

Releases 페이지의 **Assets**에서 패치 zip 파일을 받으시면 됩니다.
함께 표시되는 Source code 파일은 받을 필요 없습니다.

## 안내

- 스팀 게임 언어를 **영어**로 설정해야 적용됩니다.
- 스팀판 전용입니다. PS4, 스위치판에서는 사용할 수 없습니다.
- 설치 전에 세이브 파일을 백업해 두시길 권장합니다.
- 오역이나 버그 제보는 블로그 댓글로 남겨주세요.
